# ATA HK Project Control Center

Centralized operational dashboard for:

- Hong Kong Accounting & Tax Compliance
- Marketing execution tracking
- Strategic workbook monitoring
- HTML prototype deployment
- Operational management
- Executive visibility & reporting

This repository is designed as a lightweight deployable GitHub Pages portal that consolidates operational systems, workbook dashboards, and HTML demo environments into one centralized interface.

# Deployment

## GitHub Pages

Recommended deployment method.

### Steps

1. Push repository to GitHub
2. Open:
   - Settings
   - Pages
3. Select:
   - Branch = `main`
   - Folder = `/root`
4. Save

GitHub will automatically generate a public deployment URL.
